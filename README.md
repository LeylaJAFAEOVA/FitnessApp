# FitnessApp

iOS fitness application built with SwiftUI.

## Features

* Workout tracking
* User authentication (Firebase)
* Clean UI with SwiftUI

## Tech Stack

* Swift
* SwiftUI
* Firebase

## How to run

1. Clone the repo
2. Open in Xcode
3. Add your GoogleService-Info.plist
4. Run the app
